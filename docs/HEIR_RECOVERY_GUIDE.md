## 🏛️ What is a Rescue Bundle (`rescue.html`)?

A Rescue Bundle is a self-contained, offline-capable emergency recovery document generated by the estate owner before their departure or emergency event.

* **Zero Software Installation:** It runs locally in any modern browser (Chrome, Safari, Firefox, Edge, Brave).
* **Fully Offline Operation:** All cryptographic operations (Shamir polynomial interpolation and authenticated decryption) execute client-side using native browser Web Crypto and JavaScript.
* **No Server Contact:** Zero network egress required.

## 🔑 How Multi-Party Shamir Shares Work

The vault owner configured an **$M$-of-$N$ Threshold Scheme** (for example, **3 of 5** shares):

1. The master secret was mathematically divided into $N$ distinct share strings (e.g., Share 1, Share 2, Share 3, Share 4, Share 5).
2. Each share was distributed to a different trusted person, attorney, safe deposit box, or physical location.
3. To open the vault, **any $M$ individuals** (e.g., any 3 out of the 5) must come together and provide their shares.
4. Any number of shares fewer than $M$ (e.g., 2 shares) mathematically reveals **zero information** about the secret.

## 🛠️ Step-by-Step Heir Decryption Walkthrough

### Step 1: Secure Your Environment (Recommended)
For maximum operational security when handling high-value digital estates (e.g., cryptocurrency seed phrases, banking credentials, server root keys):
1. Copy the `rescue.html` file to a trusted laptop or desktop via USB drive.
2. Disconnect the computer from WiFi, Ethernet, and Bluetooth (Offline mode).

### Step 2: Open the Rescue Bundle
1. Double-click the `rescue.html` file.
2. It will open in your default web browser displaying the **Sovereign Emergency Recovery Vault** interface.

### Step 3: Input Required Shares
1. Check the header to see how many shares are required (e.g., *"3 of 5 Shares Required"*).
2. Contact the other designated heirs or retrieve the physical recovery cards from safe deposit boxes.
3. Paste each cryptographic share (format: `1-8f9a...` or base64 token) into the separate share input fields.

### Step 4: Decrypt the Vault
1. Click the **Decrypt Emergency Vault** button.
2. If the threshold shares are mathematically valid:
   * The browser will immediately decrypt the master payload in memory.
   * Plaintext estate instructions, passphrases, or files will appear in the decrypted output box.
   * If a file attachment was embedded, click **Download Decrypted File** to save the original document.

## ⚠️ Troubleshooting & FAQ

#### What if a share is typed incorrectly?
If a share contains a typo or missing character, the decryption engine will report `Error: Invalid share format or insufficient shares to satisfy polynomial threshold`. Verify the exact characters printed on the recovery card or digital backup.

#### Does `rescue.html` expire?
No. Standard rescue bundles are permanent, static mathematical documents and do not require any active server to remain valid.

#### Can the creator revoke a rescue bundle?
Once distributed, a physical rescue bundle can only be invalidated if the vault owner rotated the underlying accounts, re-encrypted their systems, and issued a replacement bundle (`obold rekey` / `obold rescue generate`).
